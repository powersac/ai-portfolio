Personal Agent Operating System

An inbox that arrives already triaged

Problem

Email and a to-do list grow faster than one person can clear them, and most of the work inside them is sorting, digging and drafting.

How AI is used

Every morning an agent reads the whole inbox, archives what does not need me and sends back takeaways on each newsletter. For everything else it opens the attachment, checks my calendar and reads the source for the real deadline, then recommends a call with a confidence level. I answer in one word: Draft, Research, Mine, Kill or Park. Decisions land as Gmail drafts, Calendar holds and Todoist tasks, sorted by area. On Fridays it reshapes next week's Todoist queue from my job search pipeline. Nothing is sent or created without my yes.

Result

I start with the sorting and digging done and spend my time on decisions. The instructions live in a Drive doc and a git repo, not in app settings, so every session runs the same playbook. Next step, not built yet: tag a Todoist task @agent and the agent preps it and hands it back as @review.

Household: Groceries

One list, two phones, fifteen seconds

Problem

Two people shopping and planning from one list, on phones where the work network blocks most apps.

How AI is used

One Cloudflare Worker serves the page and a small API over a single store. Each person's link is their credential. A 5am job fills the next ten days of dinners from a rotation.

Result

A tick on one phone shows on the other within fifteen seconds. No account and no app store.

Household: Chores

Shared state on four phones

Problem

A paper chart cannot tell two kids and two parents who did what, or what is owed.

How AI is used

An installable React app on a Cloudflare Worker. Each child's link only lets her check off her own tasks, and parents edit tasks, rates and payouts. Simultaneous writes retry instead of overwriting.

Result

Every phone shows the same state, with a weekly earnings summary for the parents.

Patterns across all of it

Every system shows its work.2026-Search logs each rejection with a reason. Draft Zero flags every sentence the researcher did not support.
